Automatic sync (recommended)

On the iPhone, install Health Auto Export and create an automation: REST API → URL …/api/health/ingest, format JSON, header Authorization: Bearer <your ingest token>. Full steps are in APPLE_HEALTH.md in the repository.

Manual upload

Export JSON from Health Auto Export (or use the sample file in examples/) and upload it here.
