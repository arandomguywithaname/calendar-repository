Connect a phone

On the computer, run npm run link in the project folder — it prints the secret connection link. Paste it as the one setting in the Vital app (or as the REST API URL in Health Auto Export — no headers needed). Full steps are in APPLE_HEALTH.md.

Try it with demo data

On the computer: npm run demo — it sends 35 days of sample data here, so Claude has something to talk about before any phone is connected. Real data for the same days replaces it automatically later.
