🕷️ Spider Solitaire

Moves: 0 Runs: 0/4 Best: -

Simplified single-suit Spider: this version uses all four copies of one suit for the full 52-card deck, so any descending run is automatically same-suit. Click a card to select the descending run starting there, then click a destination column (its exposed top card must be exactly one rank higher, or the column must be empty). Click "Deal 10" to deal one new card onto each column from the stock (only when no column is empty). Clear a full K-down-to-A run to bank it — bank all 4 runs to win.
